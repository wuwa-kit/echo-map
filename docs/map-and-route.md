# 地图交互与路线规划

## 声骸候选筛选与目标选择

地图和路线的最终目标始终是声骸。合鸣套装和 COST 用于缩小声骸候选列表，不直接改变地图点位或路线输入；搜索只过滤当前候选列表的可见项目，不改变候选范围。

- 合鸣套装可多选；未选套装表示不限，选中多个套装时取各套装声骸的并集。
- 合鸣套装使用独占整行的多选下拉框，每个选项显示套装图标与名称；未选套装表示不限。弹层打开时，触发器内部切换为套装名称搜索框，搜索只过滤可见选项，不改变已选套装，关闭弹层后清空搜索词。弹层顶部用三态复选框表示当前搜索结果的未选、部分选中和全选状态，显示已选数与结果数，并在右侧按可用宽度显示已选套装图标及 `+N`；点击复选框对当前结果执行全选或取消。触发器关闭时，单选显示图标与套装名，多选根据可用宽度显示尽可能多的图标，剩余数量显示为 `+N`。C1、C3 使用结果操作行内的两个独立选择按钮，默认均未选中；均未选或均选中时不限制 COST，仅选中一项时按该 COST 筛选，并与套装条件取交集。
- 用户可在候选列表中逐个选择；结果操作行用三态复选框表示套装与 COST 候选结果的未选、部分选中和全选状态，以 `N / M` 显示已选数与候选总数，点击后执行全选候选或取消候选。声骸搜索框只过滤下方固定高度列表，不改变这个计数、三态或批量操作范围；搜索无结果时在原列表容器内显示空提示。更改候选筛选不会移除已选但暂时不可见的目标。
- 只有增删最终声骸目标才会清除已生成路线；改变套装、COST 或搜索不会清除路线。
- URL 用 `sonatas` 保存套装候选筛选，用 `costs` 保存 COST 筛选，用 `echoes` 保存最终声骸目标；`sonatas` 和 `echoes` 只保存 Wiki 数字 ID，不重复写入固定前缀，搜索词不写入 URL。
- 声骸目标跨地图共享。列表同时显示当前地图点位数、全部地图点位数和覆盖地图数；当前地图没有点位但其他地图存在时，不把该声骸误报为无点位。

## 多地图路线计划

当最终声骸目标分布在多个地图时，路线面板按地图、楼层和重力状态列出独立的地图场景。点击场景可切换当前地图并查看对应点位；生成全部地图路线时，每个场景分别调用路线优化器，不虚构跨地图距离或跨地图步行连线。只有一个可规划场景时沿用单地图路线入口，多场景时仍可选择只生成当前地图路线。

多地图路线结果不写入 URL。切换地图、楼层或重力状态只切换当前显示的路线组，不清除完整路线计划；修改最终声骸、点位来源、临时点显示范围或数据集时清除路线计划。页面重新载入后只恢复筛选和地图视口，不恢复计算结果。

路线长图按地图场景标注地图、楼层和重力状态，同时提供完整长图、分地图图片和手机分卷。完整长图超过浏览器画布或 JPG 尺寸限制时，导出保留分地图图片与手机分卷，不把已经可用的结果一并丢弃。

## 定位点显示

纳入项目范围的定位点不提供手动显示筛选，始终全部启用，也不在 URL 保存图标组状态。地图仍按缩放等级逐步显示功能点、入口、服务地标等内容；缩放显示与路线起点资格相互独立。

## 地图缩放与显示

声骸、图标定位点和地区名称统一使用 `src/map/point-visibility.ts` 的层级和范围规则。显示级别以 `log2(64 / resolution)` 衡量实际地图比例，同样比例在不同底图上显示同类内容，不随底图尺寸改变。URL 继续保存 OpenLayers 视口缩放，保留现有链接的还原行为。下面是项目的默认规则，不代表已核验的游戏客户端精确阈值。

| 层级 | 显示级别范围 | 新出现的内容 | 隐藏的文字定位点 |
| --- | --- | --- | --- |
| 远景 | `[0, 2)` | 大区名称、中枢信标 | 地区名、小地名 |
| 区域 | `[2, 3)` | 地区名称 | 大区名称 |
| 周边 | `[3, 4)` | 小型信标、BOSS、秘境、挑战、无音区等功能点 | 大区名称 |
| 局部 | `[4, 5)` | 小地名、声骸、交通点、入口 | 大区名称 |
| 细节 | `[5, +∞)` | 服务、地标与待分类定位点 | 大区名称、地区名称 |

每种内容通过 `{ minZoom, maxZoom }` 定义左闭右开的显示范围，`maxZoom: null` 表示放大后持续显示。图标和声骸默认使用此规则，文字定位点按地理层级交接。声骸的显示层级与来源、XYZ 完整度无关。更改阈值只需调整统一配置，筛选说明和 Canvas 渲染共用规则。缩放时由图层样式更新，不重建数据或逐点创建 DOM。

地图不显示加减缩放按钮，通过鼠标滚轮、触控板、双击或移动端双指手势缩放。

`MapLocationBase` 表示共享的 XY 地图定位。`RegionLabel` 是文字定位点，数据保存在 `regionLabels`，不添加 Z 或 `gameCoordinate`，不作为传送起点或声骸候选。其大区、地区、小地名分别对应 `level` 1、2、3。尚未提供楼层归属的文字定位点只在主地图显示。字体沿用文鼎方新书，保持纯白、无边框、无描边。

## 地图导航与弹窗

地图切换入口固定在地图左上角，使用通用 `WuCascader` 动作入口，按官方 `country.json` 的“大区 → 地区分组 → 区域”路径导航，黑海岸直接进入区域列表。弹窗直接显示地图选项，省略顶部标题、关闭按钮和路径小标题栏。桌面使用多列级联菜单，窄屏逐级展开并保留返回按钮；窄屏筛选或路线面板展开时隐藏入口，避免遮挡面板标题。

仅浏览或关闭菜单不会改变地图。点击区域后切换所需底图并定位，同一区域可重复定位，共享底图内的导航不会按大区隐藏点位。菜单路径不写入 URL，定位结果通过地图、楼层和视口恢复。`public/data/map-data.json` 的 `mapNavigation` 保存目录和地区标签引用，由 `pnpm data:sync:map` 同步生成。`mapStateId` 只作为分组 ID，实际地图取目标地区的 `stateId`。

`src/components/base/WuCascader.vue` 接收 `options` 树，包括 `value`、`label`、可选的 `children`、`description` 和 `disabled`。组件仅在选择末级节点时发出 `select(value, path)`，按钮始终显示 `placeholder`，再次打开时从根目录开始。`showHeader` 控制标题和关闭按钮栏，`showPath` 控制桌面列标题与窄屏路径栏，默认均显示。`MapNavigationCascader.vue` 负责将地图数据转换为选项并调用 Store 定位 action，基础组件不依赖地图状态。

`src/components/base/WuPopover.vue` 是 `WuCascader` 和 `WuSelect` 共用的原生 `popover="auto"` 浮层。给组件传入 `id` 和 `anchor`，按钮通过同名 `popovertarget` 打开。内容放在默认插槽，`class` 和 DOM 事件透传到浮层。组件从原生 `toggle` 事件同步只读 `isOpen`，发出 `opened` 和 `closed`，并暴露 `show()`、`hide()`、`toggle()` 和 `updatePosition()`。插槽也提供 `isOpen` 和 `close()`。

`disabled` 阻止打开并关闭已有浮层，`isSupported` 表示浏览器是否支持 Popover API。定位支持上下方及起始、居中、末尾对齐，`width` 支持数字、`trigger`、`content` 或 `viewport`，可配置 `maxHeight`、`gap` 和 `viewportMargin`。尺寸、滚动和可视视口变化时自动定位并避让边缘。浏览器负责顶层渲染、点击外部关闭、Escape 和嵌套浮层关系。

`src/components/base/WuTooltip.vue` 使用 `popover="manual"` 提供不干扰菜单弹层的指针提示，支持上、右、下、左四个方向，并在首选方向空间不足时翻转。`content` 或 `content` 插槽提供内容，`delay`、`gap`、`viewportMargin` 和 `maxWidth` 控制显示与布局；触摸指针不触发提示。`src/components/base/WuEllipsis.vue` 提供单行省略，使用 `ResizeObserver` 和内容变更检测判断真实溢出，仅在溢出时启用 `WuTooltip`；`text`、`tooltipText`、`placement` 和 `delay` 可配置，也可通过默认插槽渲染文本。

## 移动端布局

小于 1024px 的窗口默认以地图为主，地图切换位于左上角，底部提供“筛选”和“路线”入口，筛选与路线每次只打开一个面板。竖屏面板最多占视口高度的 70%。宽度至少 500px、高度不超过 500px 的紧凑窗口使用侧面板。面板会随可视视口高度调整，避让软键盘和屏幕安全区。

筛选面板支持跳转到声骸和定位点分类，移动端内容共用纵向滚动；只有当前地图支持重力切换时才显示对应控制。

## 楼层切换

楼层入口位于地图左下角，在“主地图”按钮下直接显示 Canvas 视口内官方楼层组的完整楼层列表。只有一个组时隐藏组标题，多个组时显示各组标题。列表沿用官方组及楼层顺序，选中项不会移到前面。

候选组按完整 Canvas 的地图坐标视口识别，在初始化、Canvas 尺寸变化以及拖动和缩放结束后更新，同时保留已选和正在请求楼层所属的组。任意楼层的非透明地图图形与视口存在正面积交集时，显示其所在楼层组的全部楼层。移动地图不会隐式切层或清除路线。点击具体楼层后准备图片，成功时切换楼层和高亮，加载期间保留原显示。返回主地图后恢复视口内的组列表。列表内部使用 `WuScrollArea` 纵向滚动，“主地图”和样式切换按钮固定在顶部，加载或失败标记显示在请求的楼层行内，失败时点击该行重试。

界面省略顶部“当前楼层”文案，只通过高亮表达选中状态。XY 坐标固定在列表下方的可见地图左下角，列表高度变化不会推移坐标位置。移动端底部面板为分组列表和坐标保留上方空间，窄屏沿用相同的标题显示规则。

楼层文字列表不固定宽度，由当前楼层组和楼层名称中最长的文本自动撑开，并受可用地图宽度限制；达到上限后使用 `WuEllipsis` 省略文本，仅在实际溢出时通过 `WuTooltip` 显示完整名称。样式切换按钮覆盖在“主地图”区域右上角，不为文字列表单独保留一列宽度；切换为 56px 的竖排菱形图标栏后，按钮显示在栏外右侧。图标模式用定位图标表示主地图，浅色填充表示选中项，分隔线区分楼层组。悬停时在右侧浮出完整名称。两种布局的楼层按钮高度固定为 44px，加载标记不参与文字列表宽度计算。布局切换只修改显示偏好，不改变楼层、视口、路线或待完成请求。URL 用 `floorStyle=icons` 保存图标模式，默认文字模式省略该参数。

楼层切换列表从“局部”比例起显示，实际地图分辨率需小于等于 4。显示判断使用与点位一致的实际地图比例，不依赖不同底图各自的 URL 缩放编号。缩放结束后，远景隐藏列表并暂停附近楼层覆盖探测，放大后恢复。隐藏不会重置已选楼层、蒙层、路线或待完成的楼层请求，XY 坐标继续保持原位置。

## 楼层覆盖与图片缓存

楼层组的 `coverage` 随地图同步生成。生成过程读取同版本官方 PNG 的透明通道，将 alpha 大于等于 16 的区域合并为同组覆盖范围，再以 1024×1024 像素区间编码保存到 `public/data/map-data.json`。

列表达到显示比例时，浏览器使用完整 Canvas 视口查询实际覆盖范围。查询先以瓦片范围粗筛，再将相交矩形换算到覆盖图像素坐标，通过二分定位压缩区间并逐行判断交集，无需加载图片或逐帧读取像素。只有透明区域进入视口或仅与视口边界接触时不会命中；任意非透明区域进入视口后，整个楼层组成为候选。远离所有覆盖范围且未选中或请求楼层时隐藏候选列表，重叠组同时列出，均可直接选择具体楼层。图片轮廓只代表地图图形覆盖，不代表实测可行走边界。

单独重建当前资源版本的覆盖数据可运行：

```powershell
pnpm exec node scripts/build-floor-coverage.ts
```

完整同步继续使用 `pnpm data:sync:map`。图片失败时保留原快照，生成后运行 `pnpm data:validate`。

切换楼层时先准备整个组在当前视口内的图片，选中层优先，最多 3 张并发。准备完成后同步显示点位与图层。渲染顺序为主地图、同组未选楼层、地区名与主地图普通点位、单层 60% 深色蒙层、选中楼层、当前楼层点位与可传送点位、路线。其他组不叠加，蒙层不拦截操作。

同组切换仅调整图层层级，复用已解码图片。交互结束后向视口外扩展短边的 25%，最多预取 4 张图片、2 张并发。缓存按组保留，目标上限为 64 MiB 解码图片估算值及 8 个组，正在显示或准备的组不被驱逐。失败只重建失败或超时图片，保留原显示并允许重试，连续切换只接受最后一次请求。点位录入地图维持单层显示。

切层及返回主地图保持中心和缩放，显式切层仍会取消旧路线。URL 通过 `floor` 与视口参数恢复，楼层组由楼层或 Canvas 视口推导，不单独保存。旧的仅楼层链接首次定位后补齐视口。列表避让底部面板与安全区，长列表内部滚动。

## URL 与进行中状态

`sheet=filters` 和 `sheet=route` 保存移动面板状态，关闭时省略。原有 `panel=1` 继续独立保存桌面筛选面板的折叠偏好。搜索词、进行中的计算和路线结果不写入 URL。

关闭面板不会取消计算。改变路线相关筛选、取消计算或离开页面会释放 Worker，过期结果不会覆盖新状态。

生成路线时自动定位到未被面板及地图控件遮挡的区域。在用户手动移动地图前，收起面板会重新适配路线视野。地图保留拖动与双指缩放，关闭旋转。

## 路线规划

- 小于等于 15 个点时使用精确动态规划。
- 更多点位使用多起点最近邻和 2-opt。
- 启发式路线会检查当前地图内全部合格传送起点，不按官方数据顺序截断。
- 传送点优先使用实测 `teleportCoordinate` 作为路线起点，未录入时回退到图标点位 XYZ；地图图标不随落点移动。
- 距离使用原始 X、Y、Z 计算三维欧氏距离，不额外放大高度差。
- 不同楼层之间必须存在人工维护的 connector，否则拒绝生成穿墙路线。
- 路线在 Web Worker 中计算，不阻塞 OpenLayers 拖动和缩放。
