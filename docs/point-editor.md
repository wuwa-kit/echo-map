# 人工点位录入

## 新增和修改

从地图筛选面板点击“点位录入”，在“定位点”和“声骸点位”之间切换。录入面板与主地图共用同一张地图。

点击“新增点位”填写新记录，点击地图上的人工点位可编辑已有记录。官方声骸点位只读，保留来源及 Z=0 占位高度说明。

填写整数 XYZ、选择楼层，并补充点位信息：

- 声骸点位：添加声骸及数量，至少填写一种声骸。
- 定位点：填写名称、选择图标和传送能力；选择类型后会应用该类型的名称、图标和传送规则。
- 可传送定位点：可以补充实际传送落点 XYZ；留空时路线使用图标点位坐标。

点击“保存”后，系统检查字段完整性、坐标格式和数据引用，通过后更新点位。没有单独的核验步骤或核验状态；坐标的真实性由录入者确认。

新增定位点时可勾选“保存后复用名称和图标”，保存成功后继续新增，保留类型、名称和图标（未设置类型时也保留名称和图标），清空坐标、实际传送位置和备注，方便连续录入。传送模式恢复为类型默认值，未设置类型时恢复为不可传送。修改已有点位时，保存后仍停留在当前记录。已保存点位可以删除，删除后短时间内可撤销。

## 未保存的编辑

尚未保存的内容只保留在当前页面的内存中，刷新或关闭页面后丢弃，不提供自动暂存或恢复。切换声骸、定位点两类表单会保留各自的输入，切换正在编辑的人工点位时会提示保存或放弃修改。

不完整内容不能写入点位库。输入有误或保存失败时，表单保留原内容，修正后再次保存。“返回”结束本次录入并清空未保存表单。

## 数据保存位置

运行 `pnpm dev` 并通过本机 localhost 访问时，人工定位点保存在 `data/manual/navigation/`，人工声骸保存在 `data/manual/echo/`。两类数据均按地图拆分，主地图再按二级地区拆分，详见 [数据目录与归区](./data.md#点位分片与归区)。文件只保存完整点位，没有 `draft`、`verified` 等状态。地区根据地图与 XY 自动判断，录入时无需填写或保存。

开发服务直接读取源文件提供地图点位数据。生产构建会自动生成 `public/data/custom-echo-points.json`、`public/data/custom-navigation-points.json` 和 `public/data/official-echo-points.json`；这些发布文件已被 Git 忽略，日常录入只会产生人工源文件的 Git 改动。

在线上页面录入时，浏览器保存网站已发布的点位基准和本地新增、修改、删除记录。刷新页面或在管理界面点击“检查更新”时，会读取新版已发布数据；本地修改继续保留，双方修改不一致的点位会标记为冲突。未保存的表单内容不会进入导出文件。

## 本地点位管理

录入面板顶部的“管理点位”打开管理窗口，默认使用当前编辑类别。浏览器模式只显示本地新增点位、对已发布点位的修改和删除记录，未改动的网站点位不进入列表。可按地图、地区、操作类型和同步状态筛选，按名称、坐标或备注搜索。列表一次加载全部记录，通过虚拟滚动按需渲染，无需翻页；全选、批量操作和导出覆盖当前筛选结果，不受屏幕内可见条数限制。点击“定位”回到地图查看，点击“编辑”回到原有录入表单；手机上使用全屏卡片列表。

地图筛选按一级地区、二级地区、地表或独立子地图逐级选择，各级通过“全部”选择该地区的全部下属地图。按钮显示完整路径，再次打开时恢复当前路径；手机上单列逐级进入并支持返回。记录数根据类别、操作类型、同步状态、疑似重复和搜索条件统计，不受当前地图筛选影响。零记录范围保留显示并禁用选择，已选范围变空时仍保留筛选，可随时点击弹层顶部的“全部”重置。

操作类型分为新增、修改、删除；同步状态单独分为待收录、已收录、冲突和待确认。详情显示修改前、本地、网站三个版本。网站内容与本地修改一致时标记为已收录，可清理本地副本而保留网站点位；冲突可以选择网站版本或明确保留本地版本。撤销修改或清理已收录记录后，相应记录从本地管理列表消失，地图仍使用网站数据。附近同类点位仅在详情中提示疑似重复供核对，不自动合并或加入本地管理列表。旧浏览器快照缺少基准，首次接入时保留差异并要求确认，不将快照里缺少的新网站点位推断为删除。

批量删除、撤销修改和清理已收录均先显示操作范围供确认。存在未保存的表单时，管理界面允许查看和导出已保存内容，暂不执行数据修改或检查更新。

## 导入、导出与历史快照

“导出修改”仅包含当前类别的本地新增、修改和删除记录，保留点位 ID 及修改前内容；存在冲突或待确认记录时，先处理这些记录再提交。管理窗口可导出筛选范围或勾选记录。“完整备份”保存两类点位的本地工作记录，恢复时与当前网站数据重新对比。文件名包含用途和本地导出时间，例如 `声巡-定位点修改-20261004-153025.json`。

“导入”会先校验文件，再显示新增、修改、删除数量。修改文件只合并其中记录，其余点位保留；若当前内容已变化且与文件中的修改前、修改后内容均不一致，则拒绝整次导入，避免覆盖新内容。完整备份在浏览器模式恢复；普通点位库 JSON 仍按完整库替换并明确提示。两类表单都没有未保存修改时才可导入。

本机项目模式的管理列表直接显示项目文件中的人工点位，可以定位、编辑、删除和按类别或勾选范围导出。网站收录提交时保留原点位 ID，浏览器即可识别后续收录与冲突。

本机写盘保留保存前快照，位于 `data/cache/point-history/`，不纳入 Git。保存按文件检查内容版本：修改不同分片的页面可以分别保存，同一分片已被其他页面更新时提示冲突并保留编辑内容。跨区移动同时更新源和目标文件，写盘失败时恢复已经修改的文件。完整库导入会检查全部分片版本，防止覆盖其他页面新增的点位。分片写盘队列仅协调同一开发服务进程中的请求。
