# 官方资产浏览

通过 `/assets` 或地图筛选面板中的“浏览官方资产”打开资产库。开发服务与正式构建均提供此页面。

资产库读取 `/data/map-data.json`、`/data/catalog-data.json`、`/data/official-echo-points.json` 、`/data/official-navigation-points.json` 与 `/data/map-asset-catalog.json`，展示声骸图鉴、合鸣效果、定位点图标、探索、挑战、NPC及服务点、地表瓦片、分层瓦片和反重力瓦片。定位点图标通过官方目录保留的原图地址映射到同一像素资源，与探索、挑战和服务分类共享资产；目录未覆盖的资源按 URL 去重。探索、挑战、NPC及服务点直接从官方地图完整分类目录收录，不要求存在已纳入业务的点位；按解码后的图片尺寸与可见像素合并跨地图、跨名称和跨分类的重复图标，忽略 PNG 元数据与全透明像素的 RGB 差异。合并后保留全部名称、分类、来源 ID、地图关联及原图地址，任一名称均可搜索；跨分类资源在各分类可见，在全部资产中只显示一次。不同像素内容的图片仍分别保留。详情提供原图、来源页面、抓取时间、引用数量及来源 ID。

图片来自官方 CDN，网格在独立定高容器（一个动态视口高度，最小 480px）中滚动，使用响应式虚拟列表，仅渲染可见行及前后缓冲行，瓦片以缩略图懒加载。页面可分别下载纯地图、声骸套装与图标，以及按声骸和定位点拆分的官方、人工点位快照。

资产库支持名称、套装、类型 ID、资源路径搜索，以及分类和关联地图筛选。原有资产的地图关联来自快照点位；新增目录资产的地图关联表示该地图目录提供了此条目（含零点位条目），不代表实际点位分布。分类、地图与选中资产通过 URL 恢复，默认状态为 `/assets`。搜索词只保留在当前页面。

此页不会触发重新抓取，运行 `pnpm data:sync:assets` 可单独更新三个分类的图标目录，不修改业务点位；`pnpm data:sync:map` 和完整同步也会同步该目录。同步后运行 `pnpm data:validate`。新增目录资产只供浏览和下载，不改变定位点白名单或传送能力。部署时需要将前端路由回退到 `index.html`。
